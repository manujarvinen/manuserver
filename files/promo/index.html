MANUSERVER

A bootable Linux server that hosts (locally or in a virtual machine) a website + its PostgreSQL database.

At the moment the server is installed with Tastehopping.com: an anonymous place for YouTube videos people around the world want to expose, and for voting on them.

There are no emails, no passwords and no profiles — joining is one button, and the server hands you a made-up name and one long key that is the account.

To build the .iso you need Arch Linux on an ordinary Intel or AMD machine, and about 15 GB free. Not a Raspberry Pi or an Apple Silicon Mac.

How to use

git clone https://github.com/manujarvinen/manuserver.git
cd manuserver
./manuserver.sh build_iso     # ~20 min
./manuserver.sh vm_install

The installer asks four things — network, username, password, which disk — and does the rest itself: nginx, PHP, Postgres, and the database. It wipes the disk it installs onto. Or write the .iso to a USB stick and install onto a real computer.

Running it

manuserver               start it
manuserver vm_stop       shut it down
manuserver vm_status     is it running?
manuserver ssh mj        open a terminal on it
manuserver tunnel        put it on the public internet
manuserver backup mj     save the database to a file

No window opens — the virtual machine runs in the background, the way a server does. The site is at localhost:8080.

On the internet

A Cloudflare tunnel publishes it without touching your router: the server dials out, and visitors are passed back down that connection. Free, already installed, and switched off until you give it a token. manuserver tunnel asks for one.

Security

Root is locked, and the virtual machine is bound to your own computer, so neither the site nor SSH is visible to the rest of your network. There is no database password, because a password has no use — nothing reaches the database from the network, and only the website and the sudo user can open it. And a stored secret could be stolen.

What it does not protect you from: anyone holding an account key is that account, Cloudflare can see the traffic it carries, and the disk is not encrypted.
