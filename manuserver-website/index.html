MANUSERVER

What it is

A server — in a virtual machine, or on a real computer as a home server — for serving a website with a Postgres database.

Work in progress: today it installs the machine itself. The website and database are what comes next, and they arrive without rebuilding the .iso.

How to use

You need a computer running Arch Linux to build the .iso, with about 15 GB of free space. Nothing else has to be installed first — the build script installs what it needs.

  1. Make the bootable .iso file, a minimal custom Arch Linux server, by running the script that comes with it. Takes around 20 minutes. 
    git clone https://github.com/manujarvinen/manuserver.git
cd manuserver/manuserver_bootable_iso
./build_manuserver_iso.sh

    If it says it added you to the kvm group, log out and back in before the next step. Otherwise the virtual machine runs without hardware acceleration, and the install takes an hour instead of a few minutes.

  2. With the .iso file, install the server. It has no graphical interface — terminal only.

    The following line, run from your local Arch Linux, will install a fresh virtual machine and the manuserver into it. 

    ./run-manuserver-in-vm.sh install

    Or write the .iso to a USB stick and install it onto a real computer.

  3. The installer asks only four things — network, username, password, and which disk to use — and sets up everything else on its own. It wipes the whole disk.
  4. When it says the install is finished, close the virtual machine window. Then start the server: 
    ./run-manuserver-in-vm.sh

    Use the same username you gave the installer when you connect to it later.

Running it

The cloned GitHub repository paradoxically includes the making of the server that clones the exact same repository onto itself — which, for now, is what sets the server up. It is a multi-purpose repository. 

./run-manuserver-in-vm.sh             start it
./run-manuserver-in-vm.sh stop        shut it down
./run-manuserver-in-vm.sh status      is it running?
./run-manuserver-in-vm.sh ssh mj      open a terminal on it
./run-manuserver-in-vm.sh backup mj   save the database to a file

Replace mj with the username you gave the installer. Leave it out and it uses your own computer's username, which is only right if the two match.
